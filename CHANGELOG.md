# Історія змін

Формат за принципами [Keep a Changelog](https://keepachangelog.com/uk/).

## [0.3.0] — 2026-08-09

Реліз "активний місяць під контролем": виправлення помилок, тижневий бюджет,
live-аналітика. Без зміни версії Dexie (v2) — жодних нових персистентних
полів, вся існуюча IndexedDB зберігається без міграції.

### Додано
- `updateTransaction()` — редагування суми/категорії/дати/нотатки/способу
  оплати `expense`/`income`/`refund` на тому самому id (без подвійного обліку),
  з деталізованим `auditLog` (`before`/`after` у `detail`).
- `deleteTransfer()` — безпечне скасування переказу (м'яке видалення +
  повернення балансу резерву/накопичення), замість небезпечного редагування.
- Валідація `doTransfer()` на рівні репозиторію (сума > 0, не в ту саму
  категорію, категорія призначення активна, достатньо коштів у джерелі) +
  атомарний запис в одній Dexie-транзакції.
- Аркуш редагування операції (`OperationEditSheet`) — тап по операції в
  списку відкриває перегляд/редагування/видалення.
- Тижневий бюджет (`domain/calculations/weekly.ts`, `WeeklyBudgetCard`) —
  не ділить місячний залишок на 4, а пропорційно розподіляє на дні тижня.
- Live-звіт поточного місяця на сторінці «Підсумки» (без очікування закриття
  місяця): підсумки, витрати наростаючим підсумком, топ категорій.
- «Покрити дефіцит» та «Перерозподілити залишок» — швидкі дії на картці
  категорії, що відкривають `TransferSheet` із заповненими сумою/джерелом.
- Редагування плану категорії активного місяця (`PlanEditSheet`) +
  аудит-запис у `upsertPlan`.
- Пропозиція додати щойно створену категорію до активного місяця з екрана
  керування категоріями (`AddToMonthPrompt`).
- Пошук категорій у `ExpenseSheet` і `BudgetPage`; пошук/сортування у списку
  операцій (`OperationsPage`) + фільтри для всіх типів операцій.
- Приховування порожніх категорій на сторінці бюджету (перемикач «Показати
  порожні»).
- `docs/BANK_RECONCILIATION_DESIGN.md` — короткий дизайн майбутньої
  банківської звірки (не реалізовано цього релізу).

### Виправлено
- Видалено 44 застарілі скомпільовані `.js`-файли, випадково згенеровані в
  `src/` попереднім прогоном `tsc` без `outDir` — вони затіняли реальні
  `.tsx`/`.ts` джерела при резолві модулів Vite (dev-режим підвантажував
  застарілий JS замість актуального коду).

- Actions-workflow перенесено у `docs/ci/` як референс (токен без scope `workflow`).

## [0.2.0] — 2026-08-04

### Змінено (критично)
- **Нульовий старт**: стартові категорії тепер мають суми 0 грн; приклади сум —
  лише placeholder-підказки, не зберігаються й не беруть участі в розрахунках.
  Накопичення/резерви стартують з 0.
- **Рекомендації**: для місяця без історії не вигадується «розрахована» сума
  (0, `hasHistory=false`); суму вводить/приймає користувач — вона не стає планом
  автоматично.

### Додано
- Ідемпотентні міграції даних (Dexie v2, таблиця `appMigrations`) + тести.
- Повноцінний **редактор категорій** (`/settings/categories`): CRUD, emoji,
  розділи, пріоритети, порядок ↑/↓, вимкнення, архів/відновлення, безпечне
  видалення, дублювання, пошук/фільтри/архівні, попередження про незбережені зміни.
- Поля категорії `usableAsSource`, `favorite`, `archived`.
- PWA base path для GitHub Pages (`VITE_BASE_PATH`, `base`, роутер `basename`,
  `build:pages`).
- PWA: банер оновлення (контрольований), підказка встановлення (iOS/Android),
  `navigator.storage.persist()`.
- Ізоляція демо-даних (`demoMonthId`), підтвердження, окреме видалення демо.
- Property-based інваріантні тести фінансів (300 сценаріїв).
- Модуль числових висновків (`insights`) + інтеграція в «Підсумки» + тести.
- CI/CD: `.github/workflows/deploy-pages.yml`, `scripts/setup-github-pages.sh`,
  `scripts/check-pwa.mjs`.
- Playwright E2E реально запущено (15/15) на Desktop Chrome, Mobile Chrome,
  Mobile Safari; додано сценарії нульового старту, редактора категорій, демо.
- Документи: AUDIT_REPORT, DEPLOYMENT, PWA_TEST_REPORT, UX_AUDIT, FINANCIAL_AUDIT,
  E2E_TEST_REPORT.

### Виправлено
- iOS install-банер більше не перекриває кнопки у майстрі (показ лише на головній).

## [0.1.0] — 2026-08-04

### Додано
- Каркас проєкту: React + TypeScript + Vite + React Router.
- Грошовий тип на цілих копійках з повним набором операцій і форматуванням.
- Доменні моделі, Zod-валідація, Dexie-схема v1 з індексами та `ensureSeeded`.
- Стартовий шаблон 30 категорій за 6 пріоритетами, резерви та накопичення.
- Чисті розрахунки: залишки категорій, місячні підсумки (без подвійного обліку),
  прогноз/день, статуси категорій.
- Модуль пояснюваних рекомендацій (медіана, 60/40 для регулярних, відділення
  рідкісних викидів у цільовий резерв).
- Репозиторії та сервісний шар: місяці, плани, операції, переноси, резерви,
  накопичення, закриття місяця, створення наступного місяця, аудит.
- UI: нижня навігація з FAB, теми (світла/темна/системна), safe-area, mobile-first.
- Екрани: Головна, Операції (фільтри), Бюджет (картки з прогрес-барами),
  Підсумки (історія + порівняння), Налаштування.
- Майстер створення місяця (4 кроки) з доходом частинами, рекомендаціями,
  резервом/накопиченнями та перевіркою дефіциту з джерелом покриття.
- Аркуш швидкого додавання витрати; аркуш переносу з безпечним порядком джерел
  і захистом критичних категорій.
- Закриття місяця: чек-лист, підсумок, аналіз категорій, рекомендації, повторне
  відкриття з підтвердженням.
- Експорт/імпорт JSON з Zod, попереднім переглядом, replace/merge та авто-бекапом.
- PWA: manifest, service worker (Workbox), офлайн-кеш, іконки; тост зі «Скасувати».
- Демонстраційний opt-in сценарій.
- Тести: 25 unit/integration (Vitest), компонентний (RTL), E2E-каркас (Playwright).
- Документація: README, ARCHITECTURE, DATA_MODEL, FINANCIAL_RULES, TEST_PLAN,
  IMPLEMENTATION_PLAN, RUN_STATUS.

### Технічне
- `tsc -b`, ESLint, `vite build` — без помилок.
