# Історія змін

Формат за принципами [Keep a Changelog](https://keepachangelog.com/uk/).

## [0.1.0] — 2026-08-04

### Додано
- Каркас проєкту: React + TypeScript + Vite + React Router.
- Грошовий тип на цілих копійках з повним набором операцій і форматуванням.
- Доменні моделі, Zod-валідація, Dexie-схема v1 з індексами та `ensureSeeded`.
- Стартовий шаблон 30 категорій за 6 пріоритетами, резерви та накопичення.
- Чисті розрахунки: залишки категорій, місячні підсумки (без подвійного обліку),
  прогноз/день, статуси категорій.
- Модуль пояснюваних рекомендацій (медіана, 60/40 для регулярних, відділення
  рідкісних викидів у цільовий резерв).
- Репозиторії та сервісний шар: місяці, плани, операції, переноси, резерви,
  накопичення, закриття місяця, створення наступного місяця, аудит.
- UI: нижня навігація з FAB, теми (світла/темна/системна), safe-area, mobile-first.
- Екрани: Головна, Операції (фільтри), Бюджет (картки з прогрес-барами),
  Підсумки (історія + порівняння), Налаштування.
- Майстер створення місяця (4 кроки) з доходом частинами, рекомендаціями,
  резервом/накопиченнями та перевіркою дефіциту з джерелом покриття.
- Аркуш швидкого додавання витрати; аркуш переносу з безпечним порядком джерел
  і захистом критичних категорій.
- Закриття місяця: чек-лист, підсумок, аналіз категорій, рекомендації, повторне
  відкриття з підтвердженням.
- Експорт/імпорт JSON з Zod, попереднім переглядом, replace/merge та авто-бекапом.
- PWA: manifest, service worker (Workbox), офлайн-кеш, іконки; тост зі «Скасувати».
- Демонстраційний opt-in сценарій.
- Тести: 25 unit/integration (Vitest), компонентний (RTL), E2E-каркас (Playwright).
- Документація: README, ARCHITECTURE, DATA_MODEL, FINANCIAL_RULES, TEST_PLAN,
  IMPLEMENTATION_PLAN, RUN_STATUS.

### Технічне
- `tsc -b`, ESLint, `vite build` — без помилок.
