### Приймальний сценарій MVP (розділ 31) — статус наскрізного проходу

Пункти 1–20 покриті кодом і перевірені: unit+integration тести проходять повний
цикл (дохід частинами → бюджет → витрати → перевитрата → перенос → резерв →
закриття → підсумок → рекомендації → наступний місяць → експорт/імпорт), а
ключові екрани перевірені у браузері. Пункти 21–22 (офлайн, встановлення PWA)
забезпечені конфігурацією vite-plugin-pwa (build генерує sw.js + manifest).

## Що РЕАЛІЗОВАНО ЧАСТКОВО

- 🟡 **E2E Playwright**: сценарії написані (`e2e/lifecycle.spec.ts`), але не
  запускалися в цій сесії — потрібен `npx playwright install` (завантаження
  браузерів). Запуск: `npm run test:e2e`.
- 🟡 **Графіки**: є прості бари доходу/витрат і порівняння; складніша динаміка
  головних категорій — у беклозі.
- 🟡 **Редактор категорій в UI**: категорії керуються через seed і майстер
  (вимкнення, critical-override, суми); окремого екрана створення/зміни власних
  категорій та розділів поки немає (репозиторій `saveCategory` готовий).

## Що НЕ реалізовано (свідомо, за межами MVP / етапу 1)

- ⬜ Серверна синхронізація, акаунти, хмара (модель готова, але не потрібна зараз).
- ⬜ PIN-код і авто-блокування (архітектура сумісна; `hideAmounts` уже є).
- ⬜ Локалі ru/en (i18n-шар готовий, словники не додані).
- ⬜ Реальна перевірка на фізичних iPhone 15 Plus / OnePlus 13 — перевірено лише
  емуляцією мобільних розмірів у браузері; PWA-конфігурація відповідає вимогам,
  але апаратне тестування не проводилося.

## Відомі обмеження

- Дані живуть у IndexedDB браузера/пристрою; очищення даних сайту стирає
  статистику → потрібні регулярні експорти (є нагадування у Налаштуваннях).
- Порівняльні графіки навмисно мінімалістичні.
- 1 lint-попередження (react-refresh на `ui.tsx`, що експортує `useToast`) —
  не впливає на роботу.

## Наступний конкретний крок

1. `npx playwright install` і запуск `npm run test:e2e` для наскрізної фіксації
   приймального сценарію.
2. Додати екран редактора категорій/розділів поверх готового `saveCategory`.
3. Розширити «Підсумки» динамікою головних категорій та використанням резервів.
