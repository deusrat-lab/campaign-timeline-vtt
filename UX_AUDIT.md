# UX_AUDIT

Дата: 2026-08-04. Мета: простий, «не бухгалтерський» інтерфейс, зручний для
щоденного використання однією рукою.

## Головний екран

Показує головне без перевантаження: місяць і статус, отриманий дохід (велике
число), витрачено, доступно, нерозподілено, резерв, відкладено, профіцит/дефіцит,
проблемні категорії (лише ті, що в перевитраті/на межі), останні операції, велика
кнопка `+ Витрата`. Детальна аналітика винесена в «Підсумки».

## Швидкий розхід

Сценарій `Сума → категорія → Зберегти`:
- велике числове поле, цифрова клавіатура (`inputMode="decimal"`);
- чипи категорій (сортовані за пріоритетом), великі області натискання;
- дата за замовчуванням — сьогодні;
- коментар — необов'язковий;
- захист від подвійного збереження (кнопка блокується під час запису);
- одразу показується новий залишок категорії й попередження про перевитрату;
- тост «Витрату збережено» з дією «Скасувати».

> Примітка: спосіб оплати наразі опційний у формі; винесення його та коментаря в
> окремий блок «Додатково» — у беклозі (див. RUN_STATUS).

## Бюджет

Компактні картки: назва, план, факт, залишок, статус (колір + іконка + текст +
число — не лише колір), прогрес-бар. Прогноз/день і службові показники —
компактним рядком лише для активного місяця.

## Переноси

Спочатку сума й «Куди», далі — джерела у **безпечному порядку** (нерозподілені →
розваги → комфорт → змінні → резерв → накопичення). Критичні категорії
(пріоритет 1) та позначені «не використовувати як джерело» не пропонуються.

## Категорії (новий екран)

- Компактні картки замість великої таблиці.
- Розширені параметри — у блоці «Додатково ▾» (основна форма проста:
  `Назва → emoji → пріоритет → Зберегти`).
- Дії: створити, редагувати, дублювати, ↑/↓ порядок, вимкнути/увімкнути,
  архівувати/відновити, видалити (безпечно).
- Пошук, фільтр за пріоритетом, перемикач «Показати архівні».
- Пріоритети підписані числом + назвою + коротким поясненням.
- Попередження про незбережені зміни при закритті форми.

## Стани та безпека

- Пусті стани з поясненням і дією (немає місяця → «Створити місяць»; немає
  закритих місяців → підказка).
- Небезпечні дії (очищення бази, видалення демо, повторне відкриття місяця) —
  через подвійне підтвердження; безпечні — без зайвих кроків.
- Тост із «Скасувати» для щойно доданої витрати.
- Теми: світла/темна/системна; приховування сум.

## Адаптивність (перевірено емуляцією)

- Немає горизонтального скролу при 375×812, 430×932, 412×915 (перевірено 375/430/
  1440; 412 у тому ж діапазоні), 1440×900.
- `safe-area-inset`, `viewport-fit=cover`, мін. висота натискань 44px, фіксована
  нижня навігація з FAB.

## Залишкові UX-задачі (беклог)

- Винести «спосіб оплати» і коментар у явний блок «Додатково» у формі витрати.
- Обрані/останні категорії та «повтор останньої операції» як окремі швидкі дії.
- Drag-and-drop порядку категорій (наразі — кнопки ↑/↓).
- Графіки динаміки головних категорій (наразі — числові висновки + бари
  доходу/витрат).
