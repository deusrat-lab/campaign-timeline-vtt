## Integration (Vitest + fake-indexeddb) — `integration.test.ts` ✅

Повний місячний цикл проти реальної Dexie-логіки:
створення місяця → дохід двома частинами → плани категорій → активація →
витрати з перевитратою → перенос із кафе у продукти (з перевіркою залишків
до/після) → поповнення резерву → зняття з резерву → закриття місяця →
створення наступного місяця з пропозиціями.

## E2E (Playwright) — `e2e/lifecycle.spec.ts` 🟡

Проєкти: iPhone 15 Pro, Pixel 7. Потребує `npx playwright install`.
- перший запуск → демо-дані → активний місяць із доходом 60 000;
- додавання витрати → тост підтвердження;
- експорт даних → перевірка імені файлу `budget-backup-YYYY-MM-DD-HHmm.json`.

Розширений приймальний сценарій (ручний/автоматизований) відповідає розділу 31
ТЗ: перерахунок залишків, попередження про перевитрату, перенос, резерв,
закриття, рекомендації, імпорт, офлайн, встановлення PWA.
