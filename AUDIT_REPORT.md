  демо-накопичення мали ціль 100 000 та внесок 3 000. → Обнулено; приклади стали
  лише placeholder-підказками.
- **Міграція** для існуючих баз із ненульовими сумами. → Додано ідемпотентні
  міграції m1/m2 + таблиця `appMigrations` (Dexie v2) + тести.
- **Редактор категорій** (окремий екран): був відсутній. → Додано повноцінний
  екран «Категорії та пріоритети» з CRUD, архівуванням, порядком, розділами.
- **Base path для GitHub Pages**: `vite.config` не мав `base`, роутер — `basename`.
  → Додано `VITE_BASE_PATH`, `base`, `basename` з `BASE_URL`.
- **PWA UX**: не було ані сповіщення про оновлення, ані підказки встановлення,
  ані `navigator.storage.persist()`. → Додано `PwaBanners`, `usePwaUpdate`,
  `requestPersistentStorage`, `registerType: 'prompt'`.
- **Безпечне видалення/архів категорій**, `usableAsSource`, favorite. → Додано.
- **Демо-ізоляція**: демо змішувалося з реальними даними, не було видалення демо.
  → Додано `demoMonthId`, підтвердження, окреме видалення демо.
- **CI/CD публікація**: workflow був відсутній. → Додано
  `.github/workflows/deploy-pages.yml` + `scripts/setup-github-pages.sh`.
- **Інваріантні/property-based тести** фінансів. → Додано (300 сценаріїв).
